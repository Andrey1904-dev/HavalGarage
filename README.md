# HAVAL Гараж — каталог, кредитный калькулятор, подбор по бюджету и стоимость владения

Веб-приложение для выбора автомобиля HAVAL: каталог всех моделей официального каталога
[haval.ru/purchase/catalogues](https://haval.ru/purchase/catalogues/), сравнение комплектаций,
расчёт кредита, подбор автомобиля под ежемесячный платёж, полная стоимость владения,
план накопления и сценарий трейд-ин.

**HavalGarage — независимый информационный инструмент.** Это не официальный сайт HAVAL,
не сайт дилера и не банк. Цены, комплектации и характеристики берутся из официальных
прайс-листов производителя; расчёты являются математической симуляцией и не считаются
офертой или одобрением кредита.

### Каталог

- **11 моделей официального каталога haval.ru**: M6, JOLION, DARGO, DARGO X, F7, F7x,
  GWM POER (городские кроссоверы и пикапы) и H3, H5, H7, H9 (внедорожники HAVAL PRO).
- **GWM POER KINGKONG** в официальном каталоге отсутствует — модель показана с пометкой
  «вне официального каталога», цена известна только из тизера дилера и помечена как
  требующая подтверждения (в подборе по бюджету не участвует).
- **56 комплектаций** (включая архивные позиции прошлых лет производства, скрытые
  по умолчанию), **47 подтверждённых цен из официальных прайс-листов** (тип `msrp`).
- Фотографии — официальный CDN производителя (`img.perxis.ru`) с локальной копией в
  `public/images/models/` как резервом, если CDN недоступен.

### Расчёты

- **Аннуитет**: `A = P · r · (1 + r)^n / ((1 + r)^n − 1)`, месячная ставка `r = годовая / 1200`;
  при нулевой ставке — отдельная ветка `A = P / n`. Промежуточные значения не округляются,
  округляются только денежные суммы при выводе.
- **Обратные задачи**: сумма кредита из платежа, срок из платежа, ставка из платежа
  (численно, бисекцией), остаток долга, досрочное погашение (срок/платёж), ПДН.
- **Подбор по бюджету**: `максимальная цена = взнос + P · ((1+r)^n − 1) / (r·(1+r)^n)`,
  бюджет на эксплуатацию вычитается из доступного платежа. Обязательные ограничения
  (кузов, привод, функции, лимиты программы) исключают вариант полностью; превышающие
  бюджет варианты показываются с явной меткой превышения.
- **Стоимость владения**: подтверждённые значения (расход топлива из прайс-листа) отделены
  от пользовательских оценок; пропущенные тарифы не подставляются выдуманными цифрами;
  страховка в теле кредита не учитывается дважды.
- **План накопления**: будущая стоимость аннуитета накоплений, дата цели, проекция цены
  с явной оговоркой, что цена и программы могут измениться.

### Данные

Единый слой данных `src/data/haval/`, отделённый от интерфейса:

- `types.ts` — сущности `Model`, `Trim`, `Price`, `Offer`, `CreditProgram`, `OfficialSpecs`,
  `TrimTech`, `ModelEquipment`, `StockItem`, `PriceHistoryEntry`;
- `models.ts`, `trims.ts`, `specs.ts`, `equipment.ts`, `offers.ts`, `credit-programs.ts`,
  `stock.ts`, `prices.ts`, `price-history.ts`, `catalog.ts` (селекторы), `meta.ts` (актуальность);
- у каждой цены — сумма, тип (`msrp` / `with-benefit` / `trade-in` / `stock` / `credit` / `teaser`),
  модель и комплектация, модельный год и год производства, условия получения, ссылка на
  первоисточник, даты получения и последней проверки, статус актуальности.

Выгода **никогда не вычитается автоматически**: цена с выгодой хранится отдельной записью
и применяется в расчёте только после явного выбора пользователем.

## Запуск

```bash
npm install
npm run dev            # локальная разработка (http://localhost:5173)
npm run build          # продакшн-сборка в dist/ (base /HavalGarage/)
npm run preview        # предпросмотр сборки
npm run check          # typecheck + lint + тесты + smoke-рендер + сборка
```

Отдельные проверки:

```bash
npm run typecheck      # tsc -b --noEmit (strict)
npm run lint           # eslint (flat config, 0 ошибок и 0 предупреждений)
npm test               # 200 модульных тестов (node:test + esbuild), включая DOM-тесты в jsdom
npm run smoke          # рендер 35 маршрутов через react-dom/server
npm run seo            # генерация public/sitemap.xml по каталогу
```

Работа с данными:

```bash
npm run verify:sources                     # проверка доступности официальных прайс-листов
npm run verify:sources -- --record         # + запись результата в историю проверок
npm run verify:sources -- --record --strict # + ошибка при недоступности/расхождении
npm run update:prices                      # сбор тизеров цен (официальный источник приоритетнее)
npm run update:prices -- --dry-run         # показать распознанное, не записывая
npm run import:price-list -- price-lists/file.json   # импорт из официального прайс-листа
```

Пайплайн импорта официальных прайс-листов:

```bash
npm run catalog:discover   # найти документы на haval.ru/purchase/catalogues/
npm run catalog:import     # скачать PDF → извлечь текст → разобрать цены
npm run catalog:validate   # проверить полноту и целостность
npm run catalog:diff       # сравнить результат с текущим каталогом
npm run catalog:report     # отчёт об изменениях (--apply → журнал)
npm run catalog:full       # полный цикл
node scripts/verify-parsed-documents.mjs  # сверка с прайс-листами БЕЗ доступа к сети
```

Импорт **не перезаписывает** цены каталога автоматически: решение принимает человек
по официальному документу. Неудачный запуск не затирает результат предыдущего.

Переменные окружения (необязательные, `.env.example` — шаблон):

| Переменная | Назначение |
| --- | --- |
| `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY` | База данных для отправки заявки из калькулятора (без них приложение работает локально) |
| `VITE_SITE_URL` | Публичный адрес сайта для canonical, Open Graph и sitemap (по умолчанию `https://andrey1904-dev.github.io`) |

Секретов в репозитории нет: `.env` содержит только публичные publishable-значения
Supabase (доступ к данным ограничивается политиками Row Level Security,
`supabase/schema.sql`), а шаг CI «Guard» падает, если в отслеживаемых файлах появится
секретный ключ (`sb_secret_`, `service_role`). Приватные локальные переопределения
храните в `.env.local` / `.env.*.local` — они в `.gitignore`.

## Тесты и качество

- **200 модульных тестов** (`tests/unit.test.ts`, `tests/catalog.test.ts`,

  применение скидок и ограничения предложений, подбор по бюджету, обратный расчёт взноса,
  стоимость владения, план накопления, трейд-ин, нормализованные цены, дубликаты,
  отсутствие цен, устаревшие данные, импорт прайс-листов, целостность каталога,
  разбор текста официальных прайс-листов, отказ при неполном разборе,
  сопоставление с каталогом, детерминированность помощника, а также

  сравнения с URL, мобильное меню, ответы помощника.

  smoke, сверка каталога с официальными прайс-листами (без сети), проверка актуальности
  sitemap, сборка, контроль размера бандла.

## Развёртывание

Готовый workflow `.github/workflows/deploy.yml` публикует сборку на GitHub Pages
при пуше в `main`. Ручных настроек не требуется: шаг `actions/configure-pages`
вызван с `enablement: true` и включает Pages при первом прогоне (токен workflow
имеет `pages: write`). Секреты не нужны. Адрес после публикации:
`https://<owner>.github.io/HavalGarage/`. После передеплоя у открытых вкладок
могут устареть хеши chunk-файлов — `ErrorBoundary` покажет кнопку перезагрузки.

Маршрутизация — `BrowserRouter` с `basename` из `BASE_URL`, поэтому для GitHub Pages
добавлен `public/404.html` (стандартный SPA-редирект, сохраняющий путь).

Периодическая проверка источников: `.github/workflows/prices.yml` (еженедельно, cron) —
это **не** обновление в реальном времени; результат попадает в историю проверок, а при
изменениях создаётся pull request на ручную проверку.

## Новое в 2.0

- **История цен и мониторинг изменений**: точки проверок, журнал смены цен
  (53 записи), график динамики по комплектации, панель изменений каталога со

  собираются из одних и тех же данных.
- **Помощник по выбору** (`/advisor`): детерминированный, без языковой модели и
  без API-ключей — подбор под платёж, разница комплектаций, сравнение, структура
  платежа. Отвечает «нет подтверждённых данных», если данных нет.
- **Пайплайн импорта**: поиск документов, разбор PDF, валидация, сравнение с
  каталогом, отчёт. Офлайн-сверка по сохранённым прайс-листам работает без
  доступа к haval.ru и запускается в CI.
- **Раздел комплектаций** (`/trims`) с фильтрами по приводу, мощности, коробке,
  цене и платежу.

## Ограничения

- Расчёты — симуляция, не оферта и не одобрение кредита; индивидуальные условия банка неизвестны.
- Стоимость КАСКО/ОСАГО, ТО и транспортного налога не рассчитывается по выдуманным тарифам:
  эти поля заполняет пользователь.
- Раздел «В наличии» условный: официальный онлайн-склад haval.ru отдаёт данные только через
  клиентское приложение, поэтому VIN и остатки не публикуются (фиктивные позиции не создаются).
- GWM POER KINGKONG: официальный прайс-лист не опубликован — цена только из тизера дилера.
- Часть характеристик прошлых модельных годов (F7 2024 м.г., F7x 2025 м.г.) не заполнена:
  документы в этой итерации не проверялись, значения помечены как «нет данных».
- Автоматическое обновление в реальном времени не выполняется и не обещается.
