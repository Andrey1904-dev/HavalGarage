# HAVAL Гараж — каталог и кредитный калькулятор (дилер АГАТ, Екатеринбург)

Полноценный кредитный калькулятор для всего модельного ряда HAVAL, представленного
на сайте официального дилера **АГАТ** (Екатеринбург):
[agat-ekb-haval.ru](https://agat-ekb-haval.ru/),
[каталоги и прайс-листы](https://agat-ekb-haval.ru/purchase/catalogues/).

Проект создан на основе архива `GrantaCredit.zip` (исходный «LADA Кредит & Гараж»):
вся полезная бизнес-логика кредитных расчётов перенесена и адаптирована под HAVAL —
см. [docs/GRANTA_AUDIT.md](docs/GRANTA_AUDIT.md) и [docs/REPORT.md](docs/REPORT.md).

## Модели в каталоге

HAVAL CITY: **M6, JOLION, DARGO, DARGO X, F7, F7X** · пикапы **GWM POER, POER KINGKONG** ·
HAVAL PRO: **H3, H5, H9** (цены по прайс-листам страницы каталогов) и **H7** («скоро в продаже», без цены).

## Возможности

- Каталог моделей с фотографиями, описаниями, ценой «от» и переходом к комплектациям.
- Комплектации с подтверждёнными ценами, характеристиками и оснащением; архивные
  цены прошлых лет скрыты по умолчанию (модельные годы не смешиваются).
- Кредитный калькулятор: взнос в ₽ или %, срок 12–84 (и произвольный 1–120), ставка,
  подтверждённые скидки и госпрограмма; мгновенный пересчёт; нулевая ставка — отдельная
  ветка; валидация (взнос ≤ цены, срок, ставка, нет деления на ноль).
- Результаты: цена, скидка, взнос, сумма кредита, срок, ставка, ежемесячный платёж
  (аннуитет), общая сумма выплат, переплата, доп. расходы, всего затрат + диаграмма
  структуры платежей по годам/месяцам.
- Перенесённые инструменты исходника: «Подбор» (любые 3 из 4 полей, ставка бисекцией),
  «Досрочно» (симуляция срок/платёж, экономия процентов), «ПДН» (шкала 0–100%, пороги 30/50).
- Официальные кредитные программы (HAVAL SMART, HAVAL STANDARD, «HAVAL Кредит Jolion/Промо»,
  тарифы «Haval ОСОБЫЙ/Специальный») — с таблицами ставок «взнос × срок», требованиями
  (КАСКО, залог) и дисклеймерами. Льготная ставка не применяется к моделям вне программы.
- Механизм обновления цен: `npm run update:prices` (сбор с сайта, при ошибке данные не
  затираются) и `npm run import:price-list` (структурированный импорт прайс-листов,
  валидация, см. `price-lists/README.md`). У каждой цены — источник и дата фиксации.

## Команды

```bash
npm install
npm run dev        # локальная разработка
npm run check      # typecheck + тесты + smoke-рендер + сборка
npm test           # модульные тесты бизнес-логики и каталога (node:test)
npm run smoke      # рендер всех маршрутов без браузера
npm run build      # продакшн-сборка (base /HavalGarage/)
npm run update:prices          # живой сбор тизеров цен с agat-ekb-haval.ru
npm run import:price-list -- price-lists/file.json
```

## Структура данных

`src/data/haval/` — единый источник данных, отделённый от интерфейса:
`types.ts` (Model / Trim / Offer / CreditProgram), `models.ts`, `trims.ts`,
`offers.ts`, `credit-programs.ts`. Расчёты — `src/utils/loan.ts` (аннуитет из
исходника), `src/utils/credit.ts` (сценарий покупки, график платежей).

## Важные ограничения

- Расчёты — математическая симуляция, не оферта и не одобрение кредита.
- Цены зафиксированы 2026-10-09 по опубликованным страницам дилера; часть данных —
  тизеры «от» без раскрытия комплектации (помечены в интерфейсе).
- Автообновление в реальном времени не обещается: обновление — вручную скриптами.
- Подробности и список неподтверждённых данных — [docs/DATA_SOURCES.md](docs/DATA_SOURCES.md).
