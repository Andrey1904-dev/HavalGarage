# Импорт официальных прайс-листов

Актуальные прайс-листы 2026 года внесены в `src/data/haval/trims.ts` (цены и комплектации),
`src/data/haval/specs.ts` (технические характеристики) и `src/data/haval/equipment.ts`
(оснащение и матрицы различий) напрямую из официальных документов:
**https://haval.ru/purchase/catalogues/** (PDF-прайсы «МЦП»). Ссылки на документы хранятся
в полях `priceListUrl` / `catalogueUrl` моделей и `priceSourceUrl` комплектаций.

При публикации новых версий прайс-листов каталог обновляется тремя способами.

## 1. Проверка источников (рекомендуется перед любыми правками)

```bash
npm run verify:sources                 # доступность прайс-листов + сверка тизеров цен
npm run verify:sources -- --record     # + запись результата в историю проверок
npm run verify:sources -- --record --strict  # + ненулевой код возврата при проблеме
```

Скрипт выполняет обычные GET-запросы (без обхода CAPTCHA и авторизации), пишет отчёт
`reports/source-check.json` (не входит в Git) и **не изменяет** подтверждённые цены каталога:
расхождения фиксируются в отчёте и истории, решение об обновлении принимается по документу.

## 2. Автоматический сбор тизеров

```bash
npm run update:prices                  # сбор и запись
npm run update:prices -- --dry-run     # показать распознанное, не записывая
npm run update:prices -- --source=official   # только официальный источник
```

Приоритет источника — официальный (`haval.ru`), страницы дилера используются как вторичные.
Распознанные значения пишутся в `src/data/haval/prices.generated.json` и показываются в
каталоге отдельной панелью «Собрано автоматически»: подтверждённые цены прайс-листов они
**не подменяют**. При ошибке сети существующие данные не изменяются, а в историю добавляется
запись `outcome: 'failed'`.

## 3. Структурированный импорт прайс-листа

```bash
npm run import:price-list -- price-lists/<файл>.json
```

### Формат файла

```json
{
  "sourceUrl": "https://cdn.perxis.ru/originals/da1hsh8beucc73999j3g/original",
  "priceUpdatedAt": "2026-10-09",
  "trims": [
    {
      "modelSlug": "m6",
      "name": "Оптимум, 1.5T MT 143",
      "price": 2099000,
      "modelYear": 2026,
      "productionYear": 2026,
      "engine": "1.5T",
      "transmission": "МКП-6",
      "drivetrain": "передний",
      "validFrom": "2026-08-14"
    }
  ]
}
```

### Правила валидации

- `sourceUrl` обязателен и должен быть ссылкой на первоисточник (обычно PDF официального прайс-листа);
- `priceUpdatedAt` обязателен в формате `YYYY-MM-DD` — дата фиксации данных;
- `modelSlug` — только из списка каталога: `m6`, `jolion`, `dargo`, `dargo-x`, `f7`, `f7x`,
  `poer`, `poer-kingkong`, `h3`, `h5`, `h7`, `h9`;
- `price` — положительное число (значение строго из документа, не «примерное»);
- `modelYear` / `productionYear` — целые числа или отсутствуют;
- **дубликаты** (одинаковые `modelSlug` + `name` + `modelYear`) отклоняются;
- ошибки отклоняют импорт **целиком**: последняя подтверждённая цена никогда не заменяется
  нулём или случайным значением;
- успешный импорт добавляет запись в историю проверок `src/data/haval/price-history.json`.

## Ручное обновление каталога

Если прайс-лист изменил цены, комплектации или характеристики, правьте данные в
`src/data/haval/` (а не в интерфейсе) и обновите даты:

1. `trims.ts` — цены, комплектации, `priceValidFrom`, `priceUpdatedAt`, `priceSourceUrl`;
2. `specs.ts` — технические характеристики модели и уточнения по комплектациям (`TRIM_TECH`);
3. `equipment.ts` — базовое оснащение и матрицы различий;
4. `offers.ts` — выгоды и условия их получения;
5. `meta.ts` — `CATALOG_FIXED_AT` / `LAST_VERIFIED_AT`;
6. `price-history.json` — запись о проверке (или используйте `--record`);
7. `docs/DATA_SOURCES.md` — источники, даты, неподтверждённые данные и расхождения;
8. `npm run seo` — обновить `public/sitemap.xml`;
9. `npm run check` — типы, линтер, тесты, smoke-рендер и сборка.
