# Импорт официальных прайс-листов

Актуальные прайс-листы 2026 года уже внесены в `src/data/haval/trims.ts` напрямую
из официальных документов: **https://haval.ru/purchase/catalogues/** (PDF-прайсы «МЦП»,
ссылки — в поле `priceSourceUrl` каждой комплектации).

При публикации новых версий прайс-листов каталог цен обновляется двумя способами:

1. **Автоматический сбор** — `npm run update:prices` (scripts/update-prices.mjs):
   обычные GET-запросы к страницам agat-ekb-haval.ru, извлечение тизеров «от X ₽».
   При ошибке сети существующие данные не изменяются.
2. **Структурированный импорт** — `npm run import:price-list -- price-lists/<файл>.json`:
   для случаев, когда сайт ограничивает доступ или опубликован PDF-прайс-лист.
   Данные вносятся вручную строго из официального документа.

## Формат файла импорта

```json
{
  "sourceUrl": "https://agat-ekb-haval.ru/purchase/catalogues/",
  "priceUpdatedAt": "2026-10-09",
  "trims": [
    {
      "modelSlug": "jolion",
      "name": "Комфорт, 1.5T MT 2WD",
      "price": 2099000,
      "modelYear": 2026,
      "productionYear": 2026,
      "engine": "1.5T",
      "transmission": "МКП",
      "drivetrain": "передний",
      "validFrom": "2026-08-17"
    }
  ]
}
```

Правила:

- значения — только из официального прайс-листа (не придумываем);
- `sourceUrl` — ссылка на первоисточник;
- `priceUpdatedAt` — дата фиксации данных;
- ошибки валидации отклоняют импорт целиком: последняя подтверждённая цена
  никогда не заменяется нулём или случайным значением.
