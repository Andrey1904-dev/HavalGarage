- **Состояние:** `fixed-and-re-verified`
- **Где:** `src/utils/pdf-export.ts`, `src/components/PdfExportButton.tsx`,
  `src/utils/export.ts` (печать), `src/utils/export-data.ts` (CSV/JSON).
- **Найденный дефект:** кнопки «Печать / PDF» открывали только диалог печати,
  то есть PDF-экспорт **не работал** при том, что кнопка выглядела рабочей.
- **Исправление:** подключён pdfmake с кириллическими шрифтами (ленивый
  импорт, отдельный chunk), API кнопки изменён на
  `getOptions: () => ReportOptions | null` — отчёт собирается в момент
  нажатия, поэтому печать и PDF гарантированно одинаковы. Проверено:
  сгенерирован PDF 14 090 байт с русским текстом; pdfmake и шрифты не попали
  в точку входа.
- **Повторная проверка:** typecheck, lint, 191 тест, smoke, build — зелёные.
