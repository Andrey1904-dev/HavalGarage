## 12. Механизм обновления

1. Сбор или импорт данных из официальных страниц и прайс-листов;
2. нормализация и валидация структуры и обязательных полей;
3. сравнение с текущими данными (изменения фиксируются в отчёте);
4. сохранение подтверждённых изменений и запись истории (`price-history.json`);
5. отображение даты последней успешной проверки в интерфейсе.

Инструменты:

```bash
npm run verify:sources                     # доступность прайс-листов + сверка тизеров цен
npm run verify:sources -- --record         # + запись в историю проверок
npm run update:prices                      # сбор тизеров (официальный источник приоритетнее)
npm run update:prices -- --dry-run         # без записи
npm run import:price-list -- price-lists/f.json   # валидируемый импорт прайс-листа
```

Поведение при ошибке: последняя корректная запись сохраняется, ошибка фиксируется в истории
(`outcome: 'failed'`) и в отчёте `reports/source-check.json`, цены не обнуляются, данные
помечаются как требующие проверки. Обход CAPTCHA, авторизации и технических ограничений сайта
не выполняется. Периодический запуск — `.github/workflows/prices.yml` (еженедельно);
обновление в реальном времени не реализовано и не заявляется.
