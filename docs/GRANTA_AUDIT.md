# Аудит архива GrantaCredit.zip (исходный проект LadaGrantaCredit / MoraOS-v2)

Дата аудита: 2026-10-09. Архив распаковывался во временную директорию, в репозиторий не копировался.

## Стек и структура исходника

- Vite 7 + React 19 + TypeScript + Tailwind CSS 4, react-router-dom 7 (HashRouter),
  chart.js / react-chartjs-2, lucide-react, @supabase/supabase-js (личный кабинет),
  node:test + esbuild для тестов, playwright-core для e2e.
- Приложение — «личный кабинет владельца LADA»: авторизация (Supabase или локальный
  бэкенд), дашборд, учёт расходов/топлива, журнал ТО, «гараж», Telegram-бот и Mini App.
- Вкладка «Кредит» (src/pages/CreditPage.tsx) с тремя режимами:
  «Мой график» (кредит из БД), «Досрочно», «Подбор и ПДН».

## Интерфейсные решения, сохранённые в дизайне

- Тёмная «автомобильная» палитра с красным акцентом (заменён на фирменный HAVAL #E4002B);
- UI-кит Card/Button/Field/Select/SegmentedControl/InfoTip/SectionTitle (перенесён, `components/ui.tsx`);
- набор SVG-иконок lucide (`components/icons.tsx`); шрифты Manrope/Oswald/JetBrains Mono;
- анимации pop-in/page-enter/hover-lift/kenburns-блик; подсказки «?» для терминов (ПДН и т.п.);
- mobile-first: min-h 44px у контролов, сетки с переходом в одну колонку, отсутствие
  горизонтального скролла (таблицы — в overflow-контейнере).

## Сознательно не перенесено (с обоснованием)

| Часть исходника | Причина |
| --- | --- |
| Supabase-авторизация, личный кабинет, расходы, топливо, ТО, гараж, транспортный налог | Новый продукт — публичный каталог+калькулятор по ТЗ; учёт владельца требует внешних креденшалов, которых нет, и не относится к кредитному калькулятору HAVAL |
| Telegram-бот и Mini App (`bot/`, `lib/telegram*.ts`) | Требуют токенов бота и Supabase-функций; не входят в цель переноса |
| Зависимости sharp, playwright-core, @twa-dev/sdk | Неиспользуемые в новом продукте (требование «не добавлять неиспользуемые зависимости») |
| e2e через playwright | В песочнице нет Chromium; вместо него — smoke-рендер всех маршрутов (перенесён подход исходника) и модульные тесты |

## Тесты исходника, перенесённые в новый набор

Аннуитет (формула, нулевая ставка, NaN, обратимость, бисекция ставки, остаток долга),
ПДН (пороги, запас, сумма закрытия), досрочное погашение (срок/платёж, выгода, закрытие
взносом, «платёж меньше процентов»), даты, форматирование. Добавлены новые: сценарий
покупки (взнос ₽/%, скидка, нулевая ставка, доп. расходы, граничные ошибки), график
платежей, целостность каталога (модели, цены, источники, программы, «льготная ставка не
для всех»).
