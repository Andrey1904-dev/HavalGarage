# Известные ограничения

Честный список того, что **не** сделано или **не может** быть сделано в текущей
архитектуре. Ничего из перечисленного не выдаётся за работающую функцию.

## 1. Данные

| Ограничение | Причина | Как обходится |
| --- | --- | --- |
| Автомобили в наличии (VIN, цвета, остатки) не парсятся | `haval.ru/online-stock/` — клиентское приложение: данные загружаются скриптами браузера и не отдаются в HTML. ## 2. Расчёты

- **Расчёт не совпадает с графиком конкретного банка.** Даты платежей,
  комиссии, страховки и правила округления банка неизвестны. Результат —
  математическая симуляция, а не оферта.
- **Ставка не подбирается «по рынку».** Она берётся из официальной программы
  либо вводится пользователем и подписывается «Расчётное предположение».
- **ПДН считается по упрощённой методике** и не заменяет проверку банка.
- **Проекция цены в плане накопления** (`projectPrice`) — расчётное
  предположение о темпе изменения цены, а не прогноз.

## 3. Помощник (`/advisor`)

- Это **не** языковая модель: набор намерений ограничен шестью типами
  (бюджет, разница комплектаций, сравнение, структура платежа, компромисс,
  нераспознанный вопрос). Свободный диалог не поддерживается.
- Внешняя языковая модель не подключена: ключ API нельзя безопасно хранить в
  статическом приложении. План подключения через собственный backend — в
  [ARCHITECTURE.md](./ARCHITECTURE.md#7-почему-помощник-advisor--не-языковая-модель).
- Помощник отвечает «нет подтверждённых данных» там, где каталог не содержит
  информации, — вместо правдоподобного ответа.

## 4. Импорт

- Сетевой импорт требует доступа к `haval.ru` и `cdn.perxis.ru`. В
  изолированной среде этот доступ нестабилен; воспроизводимая офлайн-проверка
  есть только для прайс-листов M6 и JOLION (`tests/fixtures/`).
- Пайплайн **не** перезаписывает `src/data/haval/trims.ts` автоматически —
  цены применяет человек после сверки с PDF.
- Разбор опирается на структуру PDF. Если издатель изменит вёрстку
  прайс-листа, разбор может вернуть неполный результат — он будет
  отклонён (`validateParsed`), а документ получит статус
  `needs-manual-review`.

## 5. Платформа

- GitHub Pages — только статика: нет SSR, нет серверных секретов, нет
  API-роутов. Заявки на кредит уходят в Supabase (опционально); без ключей
  форма сообщает об этом.
- Нет e2e-тестов в реальном браузере: проверяется только рендер в jsdom
  (`npm run smoke`) и модульные тесты.
- Суммарный размер JS контролируется порогом 3 MiB; pdfmake и шрифты — тяжёлые
  ленивые chunk'и (~1,8 МБ), которые грузятся только при экспорте PDF.

## 6. Правовой статус

HavalGarage — **независимый информационный сервис**, не официальный сайт
HAVAL и не представительство бренда. Товарные знаки принадлежат их
правообладателям. Данные взяты из публичных официальных источников с указанием
ссылок; расчёты не являются публичной офертой.
