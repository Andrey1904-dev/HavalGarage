# Отчёт о переносе LadaGrantaCredit → HavalGarage

Дата: 2026-10-09. Ветка: `arena/5e40d6bd-havalgarage`. Архив `GrantaCredit.zip` не удалён и не изменён.

## 1. Что сделано

1. **Аудит архива** — [GRANTA_AUDIT.md](GRANTA_AUDIT.md): стек (Vite+React+TS+Tailwind),
   вся кредитная математика, сценарии и UI-решения inventoried; сначала аудит, затем реализация.
2. **Каталог HAVAL** — 12 моделей из каталога АГАТ: M6, JOLION, DARGO, DARGO X, F7, F7X,
   POER, POER KINGKONG, H3, H5, H9, H7 («скоро в продаже»). Карточки с реальными фотографиями
   соответствующих моделей, описанием, ценой «от» и переходом к комплектациям.
3. **Данные отделены от интерфейса** — `src/data/haval/` (Model/Trim/Offer/CreditProgram),
   у каждой цены `priceSourceUrl`, `priceValidFrom`, `priceUpdatedAt`; архивные модельные годы
   скрыты по умолчанию и не смешиваются с текущими.
4. **Кредитный калькулятор** — все возможности исходного калькулятора сохранены и расширены:
   аннуитет (и отдельная ветка нулевой ставки), подбор 4-го поля бисекцией, досрочное
   погашение (срок/платёж), ПДН 30/50%; добавлены: выбор модели/комплектации с ценой из
   каталога, взнос ₽/%, срок, ставка, подтверждённые скидки и госпрограмма, доп. расходы,
   мгновенный пересчёт, диаграмма структуры платежей, валидации (взнос ≤ цены, сроки 1–120,
   ставка 0–100, нет деления на ноль, «нет данных» вместо выдуманных цен).
5. **Официальные программы** — отдельная страница и тип данных: HAVAL SMART (таблица ставок
   «взнос × срок»), HAVAL STANDARD (26,2% при КАСКО), «HAVAL Кредит Jolion/Промо», тарифы
   «Haval ОСОБЫЙ/Специальный»; требования (КАСКО, залог, модельные годы) отображаются;
   льготная ставка не применяется к моделям вне программы; страховые платежи не выдумываются.
6. **Обновление цен** — `npm run update:prices` (безопасный сбор с сайта: при ошибке данные
   не затираются) и `npm run import:price-list` (валидируемый импорт прайс-листов, схема в
   `price-lists/README.md`); собранные данные показываются панелью «Собрано автоматически»
   и не подменяют подтверждённые цены. Реальное время не обещается.
7. **Тесты и сборка** — 55 модульных тестов (перенесённые из исходника + новые сценарные и
   каталожные), smoke-рендер 7 маршрутов, `npm run check` (typecheck+tests+smoke+build) — зелёные.

## 3. Сохранённая бизнес-логика архива

`utils/loan.ts` — без изменений (аннуитет, обратные задачи, бисекция ставки, остаток долга,
досрочное погашение, ПДН). Solver/ПДН/досрочное — перенесены с сохранением поведения
и текстов подсказок; дизайн-система и анимации исходника адаптированы под HAVAL.
Не перенесены (обоснование в аудите): Supabase-кабинет, расходы/ТО/гараж, Telegram-бот.

## 4. Отсутствующие / неподтверждённые данные

См. [DATA_SOURCES.md](DATA_SOURCES.md): полные PDF-прайс-листы 2026 недоступны из песочницы;
тизер DARGO X без комплектации; цены H3/H5/H9 — по прайс-листам 2024–2025 (помечены
предупреждением); H7 — без цены; оснащение части комплектаций — «нет данных»;
даты окончания акций дилером не публикуются.

## 5. Известные ограничения

- Расчёт — симуляция, не оферта/одобрение; стоимость КАСКО не моделируется.
- Автообновление цен работает только при запуске скрипта вне песочницы (сайт недоступен
  из sandbox); в песочнице сбор завершается ошибкой, данные не изменяются.
- Фотографии взяты из открытых пресс-материалов (не с сайта дилера — сайт недоступен для
  прямой загрузки в песочнице); соответствуют моделям.
- e2e в браузере заменён smoke-рендером (в песочнице нет Chromium).
