# Итоговый отчёт по проекту HavalGarage

Дата: **2026-10-09**. Ветка: `arena/459ea70a-havalgarage` (базовый коммит `6beb7f5`).
Результат: **рабочее приложение** — каталог, калькуляторы, подбор, сравнение, владение,

## 1. Что обнаружено в исходном репозитории

Аудит показал, что проект уже был переведён с LadaGrantaCredit на HAVAL и содержал рабочую базу:

- **Стек**: Vite 7 + React 19 + TypeScript 5.9 (strict) + Tailwind CSS 4 + react-router-dom 7,
  chart.js (диаграмма платежей), `@supabase/supabase-js` (заявка из калькулятора), esbuild для
  сборки тестов, `node:test` как тест-раннер. База данных не является обязательной: при отсутствии
  ключей приложение работает локально.
- **Что осталось от LADA**: только перенесённые *инструменты расчёта* (аннуитет, обратные задачи,
  досрочное погашение, ПДН, утилиты дат и форматирования) — они переиспользованы и покрыты тестами.
  Данных, компонентов, страниц и брендинга LADA в репозитории нет: архив или исходники LADA
  отсутствуют, работа велась на основе текущего проекта.
- **Что уже работало**: каталог 12 моделей, страницы моделей, комплектации с ценами официальных
  прайс-листов, кредитный калькулятор (взнос ₽/%, срок, ставка, скидки, доп. расходы, диаграмма),
  страницы кредитных программ, скрипты сбора и импорта цен, схема Supabase, 58 модульных тестов,
  smoke-рендер 10 маршрутов, сборка. Все эти функции сохранены и расширены.
- **Чего не хватало** (реализовано в этой итерации): главная страница, подбор по бюджету,
  сравнение комплектаций, стоимость владения, обратный расчёт взноса, план накопления, трейд-ин,
  избранное и сохранение расчётов, печать/PDF, разделы «В наличии» и «Источники данных»,
  официальные характеристики и оснащение по прайс-листам, типизация цен (МСP/выгода/трейд-ин/наличие),
  история проверок, SEO (метаданные, sitemap, robots, JSON-LD, canonical), аналитика с согласием,
  линтер и CI/CD.
- **Найденные дефекты данных**, исправленные в ходе работы:
  - спеццена дилера «JOLION Комфорт робот» не была привязана к комплектации и «прилипала» ко всем
    JOLION, включая механическую версию → предложению задан пустой `trimIds` с пояснением
    (конфигурация отсутствует в официальном прайс-листе);
  - одна и та же специальная цена создавала дубль записи (предложение + позиция наличия) →
    добавлена дедупликация по ключу `trimId|priceType|amount` с приоритетом позиции наличия;
  - выгода начислялась на неподтверждённый тизер POER KINGKONG, создавая фиктивную «цену со скидкой»
    → выгоды на тизеры больше не начисляются;
  - парсинг чисел с неразрывным пробелом был продублирован в нескольких местах → единая функция
    `parseLocaleNumber`.

## 9. Инструкция локального запуска

```bash
git clone https://github.com/Andrey1904-dev/HavalGarage.git
cd HavalGarage
npm install
npm run dev        # http://localhost:5173
npm run check      # typecheck + lint + тесты + smoke + сборка
npm run build && npm run preview   # проверка продакшн-сборки
```

Необязательные переменные в `.env` (шаблон `.env.example`): `VITE_SUPABASE_URL` и
`VITE_SUPABASE_PUBLISHABLE_KEY` (отправка заявки из калькулятора; без них всё работает локально),
`VITE_SITE_URL` (публичный адрес для canonical/OG/sitemap). Секретов в репозитории нет.

## 10. Адрес развёрнутой версии

Публикация выполняется workflow `.github/workflows/deploy.yml` при пуше в `main`
(слияние PR): сборка Vite с base-путём `/HavalGarage/`, артефакт GitHub Pages.
Шаг `actions/configure-pages` вызван с `enablement: true` — токен workflow имеет
`pages: write`, поэтому Pages включается автоматически при первом прогоне, без
ручных настроек репозитория. Секреты не требуются.

Адрес после публикации: **https://andrey1904-dev.github.io/HavalGarage/**
(глубокие маршруты восстанавливает `public/404.html` + скрипт в `index.html`).

Статус конкретной публикации и результат прогона приведены в разделе 13.

## 11. Известные ограничения

1. Расчёт кредита — математическая симуляция, не оферта и не одобрение; итоговые условия определяет банк.
2. Стоимость КАСКО/ОСАГО, ТО, налога и шиномонтажа не моделируется по тарифам — только ввод пользователя.
