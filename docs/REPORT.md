# Отчёт о проекте HavalGarage

Дата: 2026-10-09. Ветка: `arena/5e40d6bd-havalgarage`.

## 1. Что сделано

1. **Каталог HAVAL** — 12 моделей из каталога АГАТ: M6, JOLION, DARGO, DARGO X, F7, F7X,
   POER, POER KINGKONG, H3, H5, H9, H7. Карточки с реальными фотографиями
   соответствующих моделей, описанием, ценой «от» и переходом к комплектациям.
2. **Данные отделены от интерфейса** — `src/data/haval/` (Model/Trim/Offer/CreditProgram),
   у каждой цены `priceSourceUrl`, `priceValidFrom`, `priceUpdatedAt`; архивные модельные годы
   скрыты по умолчанию и не смешиваются с текущими.
3. **Кредитный калькулятор** — аннуитет (и отдельная ветка нулевой ставки), подбор 4-го поля
   бисекцией, досрочное погашение (срок/платёж), ПДН 30/50%; выбор модели/комплектации с ценой
   из каталога, взнос ₽/%, срок, ставка, подтверждённые скидки и госпрограмма, доп. расходы,
   мгновенный пересчёт, диаграмма структуры платежей, валидации (взнос ≤ цены, сроки 1–120,
   ставка 0–100, нет деления на ноль, «нет данных» вместо выдуманных цен).
4. **Официальные программы** — отдельная страница и тип данных: HAVAL SMART (таблица ставок
   «взнос × срок»), HAVAL STANDARD (26,2% при КАСКО), «HAVAL Кредит Jolion/Промо», тарифы
   «Haval ОСОБЫЙ/Специальный»; требования (КАСКО, залог, модельные годы) отображаются;
   льготная ставка не применяется к моделям вне программы; страховые платежи не выдумываются.
5. **Обновление цен** — `npm run update:prices` (безопасный сбор с сайта: при ошибке данные
   не затираются) и `npm run import:price-list` (валидируемый импорт прайс-листов, схема в
   `price-lists/README.md`); собранные данные показываются панелью «Собрано автоматически»
   и не подменяют подтверждённые цены. Реальное время не обещается.
6. **Тесты и сборка** — 58 модульных тестов (кредитная математика + сценарные, каталожные
   и интеграция БД), smoke-рендер 10 маршрутов, `npm run check`
   (typecheck+tests+smoke+build) — зелёные.
7. **База данных** — подключён Supabase: расчёты сохраняются в таблицу
   `credit_applications` (см. раздел 5).

## 3. Кредитная математика

`src/utils/loan.ts` — аннуитет, обратные задачи (ставка/срок/тело из платежа), бисекция ставки,
остаток долга, досрочное погашение, ПДН. `src/utils/credit.ts` — сценарий покупки (цена →
скидка → взнос → кредит → график платежей). Валидации и ветка нулевой ставки исключают
деление на ноль и отрицательные суммы.

## 4. Цены и комплектации из официальных прайс-листов производителя

Основной источник цен — страница каталогов
**https://haval.ru/purchase/catalogues/** (PDF-прайс-листы «МЦП»):

- Внесены **все 13 актуальных прайс-листов** (11 моделей + 2 прайса
  DARGO/F7x прошлых модельных годов). Текущих комплектаций — **45**.
- Линейка **HAVAL PRO с ценами**: H3 (5 комплектаций, 2 749 000–3 549 000 ₽),
  H5 (2 комплектации, 4 049 000–4 349 000 ₽), H7 (2 комплектации, 3 999 000–4 199 000 ₽),
  H9 (2 комплектации, 4 799 000–5 299 000 ₽).
- Трейд-ин выгоды **−200 000 ₽ для H3 и H7** внесены как отдельные предложения
  (`offers.ts`) с условиями программы «Лояльный трейд-ин» — базовые МЦП не искажены.
- Полные сетки: M6 (+АТ), JOLION (6 комплектаций с 2WD/4WD), DARGO (оба модельных
  года), DARGO X (Оптимум/Премиум), F7 (2024 и 2026 м.г.), F7X (2025 и 2026 м.г.),
  POER (5 версий: бензин/дизель, МТ/АТ).
- У каждой комплектации `priceSourceUrl` указывает на PDF первоисточника,
  `priceValidFrom` — на дату действия цены из документа/карточки каталога; там, где дата
  не указана (обновлённые DARGO и F7 2026 м.г.), поле оставлено пустым и показано
  предупреждение «актуальность подтвердите у дилера».
- Данные дилера АГАТ сохранены как вторичный источник: архивные цены прошлых лет,
  спеццены на JOLION в наличии, акции KINGKONG −200 000 ₽ и POER −100 000 ₽.
- Зафиксировано расхождение: тизер дилера «DARGO X от 3 199 000 ₽» против официальных
  3 499 000 ₽ — в приложении используется официальная цена.

Оставшиеся «нет данных» — в [DATA_SOURCES.md](DATA_SOURCES.md): официальный прайс-лист
POER KINGKONG не опубликован; суммы трейд-ин-выгоды для F7 2024 м.г. в документе нет;
даты окончания акций не публикуются.

## 5. База данных Supabase

- Подключение: `src/lib/supabase.ts` (ленивая инициализация клиента, безопасна для
  SSR/smoke), ключи — `VITE_SUPABASE_URL` и `VITE_SUPABASE_PUBLISHABLE_KEY` в `.env`
  (`.env.example` — шаблон).
- Функция: на вкладке «Кредит» пользователь может отправить текущий расчёт в БД как
  предварительную заявку (модель, комплектация, цена, взнос, срок, ставка, платёж,
  переплата + имя и телефон). Таблица `public.credit_applications`.
- Схема и политики: `supabase/schema.sql` — создать таблицу и включить RLS
  (публичному ключу разрешена только запись, чтение — только для авторизованных).
  Скрипт нужно выполнить в Supabase → SQL Editor; до этого отправка покажет понятную
  подсказку, приложение не ломается.
- Отказоустойчивость: при недоступной БД/сети пользователь видит сообщение об ошибке,
  калькулятор продолжает работать локально; статус «БД подключена / не настроена»
  показан на форме.

## 6. Известные ограничения

- Расчёт — симуляция, не оферта/одобрение; стоимость КАСКО не моделируется.
- `npm run update:prices` собирает тизеры со страниц дилера, которые на момент фиксации
  отвечают ошибкой 500 — при недоступности источника данные не изменяются. Официальные
  прайс-листы производителя (haval.ru / cdn.perxis.ru) доступны и уже внесены вручную;
  их повторное обновление выполняется по мере публикации новых версий документов.
- Фотографии взяты из открытых пресс-материалов (не с сайта дилера — сайт недоступен для
  прямой загрузки в песочнице); соответствуют моделям.
- e2e в браузере заменён smoke-рендером (в песочнице нет Chromium).
